# Scent by Menina Landing Page

A premium, responsive one-page fragrance boutique website built for Scent by Menina in Osogbo, Osun State.

## Features

- Glassmorphism-inspired luxury UI
- Responsive mobile-first layout
- Scroll reveals and subtle parallax
- Product/category showcases
- Founder story and customer reviews
- WhatsApp ordering with prefilled messages
- Bumpa store and Instagram links
- Retail, wholesale and dropshipping positioning
- Local SEO metadata + JSON-LD
- Reduced-motion accessibility support
- No fabricated product pricing or reviews

## Local preview

Open `index.html` directly, or serve the folder locally:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploying to Vercel

This is a static site. Import the repository into Vercel and deploy with no build command required. Set the output directory to the project root if prompted.
